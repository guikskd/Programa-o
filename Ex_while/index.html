● Script Ativo

Calculadora de Tabuada

Este aplicativo utiliza janelas nativas do sistema para processamento de dados. Siga as instruções abaixo para visualizar a saída:

  1. Responda ao Prompt na sua tela inserindo um número válido.
  2. Abra as Ferramentas do Desenvolvedor pressionando F12 (ou Ctrl + Shift + I).
  3. Clique na aba Console para ver o resultado da tabuada impresso.
💡 Dica: Caso queira rodar o programa novamente, basta atualizar a página (F5).
